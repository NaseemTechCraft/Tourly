# Tourly

## Overview

Tourly is a modern travel and tour landing page designed to showcase destinations, tour packages, and travel experiences. It focuses on delivering a clean user interface, responsive design, and smooth navigation for visitors exploring trips and travel inspiration.

## Features

- Responsive layout optimized for desktop and mobile
- Attractive destination showcase section
- Clear tour package presentation
- Contact or booking prompt section
- Smooth scrolling and navigation experience

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Install required dependencies.
4. Run the application.

## Usage

Open `Index.html` in a web browser to view the travel website. Navigate through destination sections, tour packages, and contact prompts to explore the project's design and content presentation.
